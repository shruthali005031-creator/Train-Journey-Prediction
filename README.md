# Train Journey Prediction ML Project

## 📌 Project Overview

This project focuses on analyzing train journey data and predicting journey duration using Machine Learning.

The project includes data preprocessing, feature engineering, data analysis, visualization, model training, model evaluation, and an interactive Streamlit dashboard.

## 🎯 Objectives

- Analyze train journey data
- Clean and preprocess the dataset
- Perform feature engineering
- Analyze important journey features
- Train a Machine Learning model
- Predict journey duration
- Evaluate the model
- Create an interactive dashboard

## 📊 Dataset

The dataset contains train journey information such as:

- Train Number
- Station Code
- Station Name
- Route Number
- Arrival Time
- Departure Time
- Distance
- Train class information

Additional features were created during preprocessing for Machine Learning.
